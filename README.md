## Overview

Distributes students across exam halls using a seating algorithm designed to
minimize cheating, with import from Word and Excel and export of formatted
reports. The interface is fully localized in Arabic.

## Features

- Fully Arabic UI with multi-department support
- Student import from Word and Excel
- Anti-cheating seat-distribution algorithm
- Formatted Word and Excel report export

## Getting started

```bash
pip install -r requirements.txt
python main.py
```
